# Sheaside v0.5.1

Excelの右側にワークシート一覧を表示するVSTOアドインです。既存のVisual Studioソリューションと.NET Framework 4.8プロジェクトを使用しています。

v0.4.1の原因調査、グラフシートの操作対応表、変更ファイルとMicrosoft 365実機確認手順は[グラフシート対応の記録](docs/v0.4.1.md)を参照してください。

v0.5の選択操作・設計・変更ファイル・Microsoft 365実機確認手順は[複数選択の記録](docs/v0.5.md)を参照してください。Ctrl／Shift／Ctrl＋Shift、一覧内のCtrl＋A、Escに対応し、選択集合をウィンドウごとに保持します。Excelのシートグループ化は行いません。複数選択中は管理操作とドラッグ並び替えを無効にし、1件に戻してから操作します。

v0.5.1でCtrl＋Shiftの範囲追加と、複数選択からドラッグした際の意図しない範囲選択を修正しました。[原因・変更内容・実機確認手順](docs/v0.5.1.md)を参照してください。

## 実装した動作

- ブックを開くと、右側に「Sheaside」カスタムタスクペインを表示します。
- ワークシートと独立したグラフシートをExcelのタブ順で縦に表示します。グラフシートには「［グラフ］」を付け、クリック、または選択してEnterで切り替えられます。セル上の埋め込みグラフは一覧に含めません。
- ブック／ウィンドウの切り替え時と、Excel側でのシート切り替え時に一覧を更新します。
- リボンの［Sheaside］タブ → ［Sheaside］ボタンで、そのウィンドウのパネルを表示・非表示にします。パネルの×ボタンとも状態を同期します。
- ウィンドウのHwndごとにパネルを管理します。同じブックの［新しいウィンドウを開く］にも対応する構成です。新しいウィンドウでは初期表示し、表示状態の永続保存は行いません。
- イベントでの更新に加え、Excelが前面・操作可能で、アクティブウィンドウのパネルが表示されている場合だけ、3秒間隔で状態を照合します。タイマーによるシート取得はそのウィンドウに限定し、背面の一覧はウィンドウ切り替え時に更新します。ドラッグ中は構成検証のみ行います。
- Hiddenには「（非表示）」、VeryHiddenには「（VeryHidden）」を付けます。クリックしても再表示せず、右クリック操作を案内します。選択行は背景色、実際のアクティブシートは「●」で区別します。グラフシートにも同じ表示を適用します。
- 右クリックで表示シートを非表示に、Hiddenを再表示できます。VeryHiddenは専用の［VeryHiddenを再表示…］でシート名の確認が必要です。最後の表示シートは非表示にできません（表示中のグラフシートも数えます）。
- 行左側の小さな色見本にExcelのタブ色を表示します。［タブの色］→［色を選択…］で変更し、［色なし］で解除できます。色なしと黒を区別し、文字色・選択背景はWindowsのシステム色を使用します。挿入ラインは行描画の後に縁付きで描画します。
- 一覧のダブルクリックで名前を変更します。現在の名前を初期表示し、入力エラー時はダイアログ内で修正できます。
- 一覧の右クリックメニューから追加・名前変更・複製・削除を行えます。右クリックした行が対象になり、空白部分では追加のみ利用できます。
- 一覧上部の［+ シートを追加］でも追加できます。選択シートの直後、未選択の場合はブック末尾に追加します。複製は必ず元シートの直後です。
- 削除前に対象シート名を表示して確認します。最後の表示シートは削除できません（表示中のグラフシートも数えます）。Excelの警告表示設定は成功・失敗にかかわらず元の値へ戻します。
- 読み取り専用・ブック構成保護・従来の共有ブックでは管理操作を拒否し、理由を表示します。
- 名前は空白のみ、32文字以上、不正文字、先頭／末尾のアポストロフィ、予約名History、既存名との重複を検証します。重複検証にはグラフシートも含め、大文字小文字を区別しません。
- 操作後は一覧を更新し、追加・複製したシート、または名前を変更したシートを選択します。削除後は残った選択シート、またはアクティブシートへ戻します。更新のない行の置き換えや全件クリアは行いません。
- 管理操作の開始時にウィンドウ・ブック・対象シートを固定し、ダイアログ後に再検証します。メニューを開いている間はその一覧を、操作中はタイマー更新を保留します。CodeNameが空のシートも識別できます。
- 一覧を左ボタンでドラッグすると挿入ラインを表示し、ドロップで実際のシート順を変更します。開始にはWindows標準のドラッグ閾値を超えるマウス移動が必要です。
- 行の上半分でその前、下半分でその後、一覧末尾の空白で最後のワークシートの後に挿入します。先頭・末尾付近でドラッグを続けると自動スクロールします。自分自身の前後など順序が変わらない位置では何もしません。
- ドラッグ中にブック・ウィンドウが切り替わると中止します。別パネル・別ブックへのドロップ、コピー、一覧外へのドロップは受け付けません。Escでも中止できます。
- ドラッグ中は一覧更新を保留し、開始時のシート構成・順序・対象ブックをドロップ直前に検証します。失敗・中止・成功のいずれでもExcelから順序を読み直し、移動したシートの選択を維持します。表示だけの先行並び替えはしません。
- 非表示／VeryHiddenシートも移動できます。Excelの直接移動が拒否される場合への対応として、非表示の移動元は画面更新を止めた間だけ一時表示し、`finally`で元の表示状態と画面更新設定を復元します。元のアクティブシートも可能な範囲で維持します。移動では`DisplayAlerts`を変更しません。
- グラフシートも一覧・ドラッグ対象に含め、先頭・末尾はExcelのタブ全体の先頭・末尾を意味します。Worksheet.Move／Chart.Moveを呼び分けます。非表示の移動先も画面更新停止中だけ一時表示して、Excelが挿入位置を変えてしまう問題を防ぎ、移動後の実際の順序も検証します。
- Excel側で行われた変更も一覧に反映します。ドラッグ途中で追加・削除・外部からの並び替えがあれば、そのドラッグを中止します。

## Visual Studioでの動作確認

1. Visual Studio 2026 Communityで`Sheaside.slnx`を開き、Sheasideをスタートアッププロジェクトにします。Office/SharePoint開発ツール、.NET Framework 4.8開発ツール、VSTO Runtime、Windows版Excelが必要です。
2. 構成を`Debug / Any CPU`にし、［ビルド］→［ソリューションのビルド］を実行します。
3. F5でExcelを起動します。ブックを開いていない開始画面では、空白のブックを作成してください。
4. ワークシートを2枚以上用意します。右側に「Sheaside」が表示され、ブック内のワークシート名と順番が一致することを確認します。
5. 一覧で別のシートをクリックし、Excelのアクティブシートが切り替わることを確認します。キーボードでは矢印キーで選んでEnterを押します。
6. ［Sheaside］タブの［Sheaside］ボタンでパネルを非表示・再表示します。パネルの×で閉じたときにボタンの押下状態も解除され、ボタンから再表示できることを確認します。
7. 別のブックを開き、ウィンドウを行き来して、それぞれのブックの一覧とアクティブシートが表示されることを確認します。
8. ［表示］→［新しいウィンドウを開く］で同じブックの2つ目のウィンドウを作成します。一方のパネルを非表示にしても他方が表示されたままで、一覧のクリックがそのウィンドウのシートを切り替えることを確認します。
9. ブックを変更して閉じる際、保存確認で［キャンセル］を選んでもパネルが残ることを確認します。その後、不要なウィンドウを閉じても残りのウィンドウで操作できること、最後のブックを閉じて新規ブックを作成しても一覧が表示されることを確認します。
10. 非表示シート、長いシート名、日本語のシート名、グラフシートのあるブックでも確認します。非表示シートをクリックしても表示状態は変わりません。セル編集中などに切り替えが失敗した場合は、編集を完了して再試行してください。

アドインが表示されない場合は、Excelの［ファイル］→［オプション］→［アドイン］でCOMアドインのSheasideと、使用できないアイテムを確認してください。F5が目的と異なるExcelを起動する場合は、プロジェクトのデバッグ設定で起動対象のExcel.exeを確認してください。

### v0.2の追加確認

保存が必要な実データではなく、テスト用ブックで確認してください。

1. ［+ シートを追加］と右クリックの［シートの追加］の両方で追加し、配置と選択を確認します。空白部分の右クリックからは末尾に追加できることも確認します。
2. ダブルクリックと右クリックの両方で名前を変更します。現在の名前が入力済みであること、キャンセルで変わらないこと、変更後に同じシートが選択されることを確認します。
3. 空名、重複名（大文字小文字違い・グラフシート名も含む）、`a/b`、`'test`、`History`、32文字を入力して拒否されること、日本語名と31文字は使えることを確認します。
4. 値や書式のあるシートを複製し、元シートの直後に内容が複製され、新しい行が選択されることを確認します。
5. アクティブではない行を右クリックして削除し、確認にその行の名前が表示されることを確認します。［いいえ］では変化せず、［はい］でそのシートだけが消えることを確認します。
6. 表示シートが1枚だけの場合、ほかに非表示シートがあっても削除できないことを確認します。表示中のグラフシートが残る場合は最後の表示ワークシートを削除できることも確認します。
7. 読み取り専用・構成保護付きブックで管理操作が拒否され、一覧選択とリボン表示切り替えは引き続き利用できることを確認します。
8. 2ブック・同一ブックの2ウィンドウで操作し、対象外のブックが変わらないことを確認します。Excel側のシート切り替えとパネルの選択同期、リボン表示・非表示も再確認します。
9. 非表示／VeryHiddenシートの名前変更・複製・削除、セル編集中の操作を確認します。Excelが拒否した場合にエラーを案内し、元の警告表示設定が維持されることを確認します。Excel 2013の自動検証では非表示シートの複製直後の削除が拒否されるケースがあり、Microsoft 365では別途確認が必要です。

### v0.3のMicrosoft 365実機確認

1. F5で起動し、テスト用ブックにA・B・C・Dなど4枚以上のワークシートを用意します。通常クリック・Enter・ダブルクリックによる名前変更・右クリックが従来どおり動くことを確認します。
2. 左ボタンを押したまま少しだけ動かし、すぐドラッグにならないことを確認します。閾値を超えて動かすと、移動先の上半分／下半分で挿入ラインが切り替わることを確認します。
3. DをAの上半分へ、続いて先頭のシートを最後の行の下半分へ移動します。前方・後方・先頭・末尾でExcelのシートタブと一覧の順序が一致し、移動した行が選択されたままであることを確認します。
4. 一覧下の空白へドロップして末尾へ移動できること、自分自身の上半分／下半分では順番が変わらないことを確認します。多数のシートで上下端の自動スクロールも確認します。
5. Esc、一覧外へのドロップ、別ブック／同一ブックの別ウィンドウへの切り替えをドラッグ中に行い、中止されることを確認します。切り替えて元のウィンドウへ戻っても、元のドラッグは再開されないことを確認します。
6. 非表示・VeryHiddenシートを前後・先頭・末尾へ移動します。表示状態を保ち、元の表示シートの内容が維持され、パネルでは移動した行が選択されることを確認します。非表示シートを移動先にした場合も確認します。
7. グラフシートをワークシート間や末尾に挟んで移動します。v0.4.1ではグラフシートを含めたExcelのタブ順全体が一覧と一致することを確認します。
8. 構成保護・読み取り専用のブックでは移動が拒否されることを確認します。ドラッグ途中に外部マクロなどでシート構成を変えた場合は中止され、実際のExcelの順序へ一覧が戻ることも確認します。
9. 追加・名前変更・複製・削除、ブック切り替え追従、Excel側のアクティブシートとの同期、リボン表示切り替えを再確認します。

### 自動チェック

Debugをビルドした後、以下を実行できます。外部テストフレームワークは不要です。

```powershell
# 名前・既存UI・並び替え位置・ドラッグ閾値・中止・ドロップの検証
.\tools\Test-Sheaside.ps1
# 上記に加えて、独立したExcelインスタンスとテスト用ブックでInterop操作を検証
.\tools\Test-Sheaside.ps1 -Excel
```

`-Excel`は新規Excelインスタンスを起動し、テスト専用ブックを作成します。読み取り専用検証の一時ファイルは`Sheaside/obj/SmokeTests`に作成して削除し、終了時に専用ブックとExcelを閉じます。VSTO上の実際のマウス操作やリボンの確認は手動確認の対象です。

## 開発用署名

元のプロジェクトにClickOnce署名設定がなく、標準VSTOビルドが失敗したため、1年間有効なローカル開発用証明書を作成し、署名設定を追加しています。PFXはこの作業環境に生成済みです。配布には配布用の署名証明書を使用してください。

別の環境へソースのみを持っていく場合は、Visual Studioのプロジェクトプロパティ［署名］でテスト証明書を作成・選択するか、PFXが存在しない状態で次を実行してください。

```powershell
powershell.exe -NoProfile -File .\tools\New-DevelopmentCertificate.ps1
```

スクリプトは既存の証明書を上書きしません。証明書を生成すると、プロジェクト内の`ManifestCertificateThumbprint`も更新します。秘密鍵を含むPFXはGit管理から除外しています。通常のVSTOビルドでは、標準のOfficeToolsターゲットが開発用証明書の処理と現在のユーザーへのアドイン登録を行います。

## v0.4のMicrosoft 365実機確認

Visual StudioのDebug / Any CPUでF5起動し、保存不要なテスト用ブックで確認します。

1. 3枚以上のシートを用意し、一覧の選択背景と、アクティブシートの「●」を確認します。右クリックで別行を選ぶと「●」は実際のアクティブ行に残ります。
2. ［非表示にする］でHiddenに変更し、「（非表示）」表示・選択維持を確認します。クリック・Enterでも再表示されず、操作案内が出ることを確認します。［再表示］で元に戻します。
3. VBAエディターの対象ワークシートのプロパティでVisibleを`2 - xlSheetVeryHidden`に設定し、Excelに戻ります。「（VeryHidden）」が表示され、通常の［再表示］が無効になることを確認します。
4. ［VeryHiddenを再表示…］で対象名と既定の［いいえ］を確認します。キャンセルで変化せず、［はい］で表示状態になることを確認します。
5. 表示シートが1枚になるまで隠し、最後の1枚の非表示が拒否されることを確認します。表示中のグラフシートがあれば、最後の表示ワークシートは隠せます。
6. ［タブの色］で赤・黒・白・任意のRGB色を選び、Excelのタブと行左側の色見本が一致することを確認します。色なしに戻し、文字と選択状態が読みやすいことを確認します。色ダイアログのキャンセルも確認します。
7. Excel側で色・表示状態を変更し、通常のExcel画面に戻って約3秒以内、またはシート／ウィンドウ切り替えで反映されることを確認します。パネル非表示中や他アプリが前面の間は更新せず、戻ったときに反映します。
8. 2つのブックと同じブックの2つのウィンドウを開き、同名シートにも別々の色・状態を設定します。対象のブックだけが変わり、同じブックのもう一方の一覧は切り替え時に同期することを確認します。
9. ブック構成の保護・読み取り専用で色と表示状態の変更が拒否され、一覧選択・リボンの表示切り替えは維持されることを確認します。
10. 多数の行でスクロールした位置から色・表示状態を変更し、選択とスクロール位置が維持されることを確認します。長い日本語名、Windows高コントラスト／拡大表示でも確認します。
11. 色付き・Hidden・VeryHiddenの行を前後・先頭末尾へドラッグし、挿入ラインが見えること、色・表示状態・選択が維持されることを確認します。Esc中止・ブック切り替え中止も確認します。
12. 追加・名前変更・複製・削除、Excel側のアクティブ同期、リボン切り替え、および上記v0.3の確認を再実施します。

### v0.4の既知の制約

- 表示状態・タブ色の専用変更イベントがないため、イベントが発生しない変更には最大約3秒の遅延があります。セル編集中・ダイアログ中はExcelが呼び出しを拒否する場合があり、操作可能になった後に再取得します。
- WinFormsの標準表示はWindowsのシステム色に従います。Office独自のダークテーマには連動しません。Excelのテーマ色は現在の解決済みRGBを表示し、色選択ダイアログからの設定は固定RGBです。
- v0.4.1ではグラフシートも管理対象です。VeryHiddenへ変更する機能と、新規グラフシートの作成機能はありません。
- 読み取り専用・構成保護・従来の共有ブックでは、色変更も含めて管理操作を拒否します。
- v0.4.1まではMicrosoft 365で実機確認済みです。v0.5の実機確認は未実施で、自動テスト環境はExcel 2013です。

コマンドラインでのDebugビルド例:

```powershell
& 'C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Current\Bin\MSBuild.exe' `
    .\Sheaside.slnx /t:Build /p:Configuration=Debug '/p:Platform=Any CPU' /p:VisualStudioVersion=18.0
```

タスクペインはウィンドウを明示して作成し、終了時にはVSTO自身に破棄を任せます。このライフサイクルとRibbon XMLの接続は、Microsoftの[カスタムタスクペイン](https://learn.microsoft.com/en-us/visualstudio/vsto/custom-task-panes)と[Ribbon XML](https://learn.microsoft.com/en-us/visualstudio/vsto/ribbon-xml)の説明を参照しています。

名前の基本制約はMicrosoftの[ワークシート名の規則](https://support.microsoft.com/en-gb/excel/rename-a-worksheet)を参照しています。

タブ色は[Tab.ColorIndex](https://learn.microsoft.com/en-us/office/vba/api/excel.tab.colorindex)で色なしを判別し、[Tab.Color](https://learn.microsoft.com/en-us/office/vba/api/excel.tab.color)で現在のRGB色を取得・設定します。

並び替えは[Worksheet.Move](https://learn.microsoft.com/en-us/office/vba/api/excel.worksheet.move)のBefore／Afterの片方を必ず指定します。ドラッグの開始閾値とキャンセルはWinFormsの[DoDragDrop](https://learn.microsoft.com/en-us/dotnet/api/system.windows.forms.control.dodragdrop)と[ドラッグ＆ドロップイベント](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/input-mouse/drag-and-drop)に沿って実装しています。
