# Sheaside 1.0 Release Candidate

Excelのシートを縦型一覧で管理するWindows向けVSTOアドインです。C# / .NET Framework 4.8 / Excel Interop / WinFormsを使用します。RC識別子は `1.0.0-rc.4`。Microsoft 365での実機確認後に正式版を確定します。

## 操作

- ワークシートと独立したグラフシートをExcelのタブ順で表示。クリック・Enterで切り替えます。非表示シートは勝手に再表示しません。
- Ctrlで選択切り替え、Shiftで範囲置換、Ctrl＋Shiftで範囲追加。一覧内のCtrl＋Aで表示行を全選択、Escで表示範囲内のアクティブ行へ戻します。Excelのシートグループ化は使いません。
- 選択済み行の右クリックは複数選択を維持し、未選択行の右クリックはその行だけを選びます。
- 同じ右クリックメニューから単一・複数の複製、削除、非表示、再表示、タブ色変更／解除を実行できます。複数選択時は追加・名前変更を無効にします。名前変更はダブルクリックにも対応します。
- 削除だけ対象件数・全対象名・取り消せない旨を確認します。他の管理操作の確認と正常終了ダイアログはありません。失敗・部分成功・保護による拒否は通知します。
- リボン［表示 → Sheaside］の［非表示も表示］［VeryHiddenも表示］を独立して切り替えます。両方の初期値はOFF。設定は再起動後も復元し、同一Excelインスタンスの各パネルへ反映します。VeryHiddenを一覧に表示すると、VeryHiddenへの変更・再表示も利用できます。
- 名前検索は大小文字を区別しない部分一致。文字がある間だけ［解除］を表示し、検索文字列だけを消します。Hidden／VeryHiddenの設定は変更しません。種類・状態のフィルターUIは廃止しました。
- 絞り込みで消えた行は選択から除外し、解除しても選択を復活させません。全選択対象が除外された場合は表示範囲内のアクティブ行へ戻り、それもなければ選択0件です。
- 単一・複数選択をドラッグで並び替えます。Ctrl／Shiftを離してからドラッグしてください。選択済み行からは選択集合を維持し、未選択行からはその行だけを移動します。検索中・表示条件適用中も利用できます。選択シートの元の相対順序を維持します。
- 選択背景、アクティブ行の●、タブ色は独立した表示です。種類は表／棒グラフ、状態はHidden＝目に斜線・VeryHidden＝鍵のアイコンで表します。行のツールチップとアクセシビリティ説明に種類・状態を残します。
- 設定画面・初期表示設定は廃止。新しいExcelウィンドウではパネルを自動表示しません。旧設定値は安全に無視します。Officeテーマ追従・Windows高コントラスト優先を維持し、パネル位置はExcel標準のドラッグ操作で変更できます。
- リボン［表示 → Sheaside → シート一覧］とパネルの×で、ウィンドウごとの表示を切り替えます。独立したSheasideタブは廃止しました。

上部の追加・削除ボタンと右クリックメニューは同じ安全性チェックを使います。タブ色はテーマ色・濃淡・標準色・任意RGBから選択でき、テーマ指定はブックのテーマ変更に追従します。

絞り込み中の移動先は実際のWorkbook.Sheetsを基準にします。先頭は最初の表示行の直前、末尾の空白は最後の表示行の直後です。除外された行を直接移動せず、それらの相対順序を維持します。途中失敗は中断・結果報告し、実順序を再取得します。

## 安全性と同期

内部IDで対象を管理し、ダイアログ後・各処理直前に所属ブック、対象の存在、名前・表示状態、保護などを再検証します。削除・Hidden／VeryHidden変更は最低1枚の表示シートを残します。読み取り専用・構成保護・従来の共有ブックでは管理操作を拒否します。

一括操作は最初の失敗で中断し、成功・失敗・スキップ・未処理を報告します。成功済み変更はロールバックしません。DisplayAlertsや一時表示で変更した設定はfinallyで復元します。操作後はExcelの実状態を再取得します。

イベント更新に加え、Excelが前面・操作可能でアクティブなパネルが表示されている場合のみ3秒間隔で状態を照合します。操作・ドラッグ・メニューとの競合を避け、ウィンドウ別の選択集合を維持します。

## 開発・検証

Visual Studio 2026 Community、Office/SharePoint開発ツール、.NET Framework 4.8開発ツール、VSTO Runtime、デスクトップExcelを使用します。`Sheaside.slnx`をDebug / Any CPUでビルドし、F5で起動します。

別環境でPFXがない場合は、プロジェクトの［署名］で開発用証明書を指定するか、`tools/New-DevelopmentCertificate.ps1`を実行します。PFXはGit管理しません。

```powershell
# Debugビルド後
.\tools\Test-Sheaside.ps1
.\tools\Test-Sheaside.ps1 -Excel
# 切り分け用
.\tools\Test-Sheaside.ps1 -Excel -BatchOnly
# 専用Excelを一時表示してホスト内のリボン・検索・ウィンドウ別UIを確認
.\tools\Test-ExcelUi.ps1

```

RC4の検証結果は[開発記録](docs/rc.4-progress.md)を参照してください。今回の対象はExcel 2013上のリボン・一覧UIとドラッグ改善です。MSIの再作成、Microsoft 365へのインストール、GitHub Releases公開は実施していません。既存のMSI関連スクリプト・成果物はRC2のままです。

自動テストは専用ブック・独立したExcel 2013（15.0）インスタンスを使用します。一部の既知の削除拒否は、対象保持・警告設定復元を検証する分岐を含みます。Microsoft 365での成功を代用しません。ホスト内UIの検証範囲・結果は開発記録に記載しています。実マウス操作・実OS倍率・別PCへのインストールは手動確認が必要です。
