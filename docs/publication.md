# 公開リポジトリへの移行

2026-10-24、個人メールアドレスを公開対象から除くため、元のリポジトリを非公開の `nyo-ro/Sheaside-private` として保存し、匿名化した履歴を別の新規 `nyo-ro/Sheaside` に移しました。forkとしては作成していません。

- 既存37コミットの作者/コミッターとrc.5タグの作成者メールはGitHub noreplyへ変更。ソースのツリーは移行前と完全一致することを確認しました。
- コミットIDは変わります。過去の開発記録に含まれるIDは旧非公開履歴の値であり、新しい公開履歴では解決できないものがあります。
- 最新UI修正の公開履歴IDは `b44d01e`、配布準備は `495fdbe`。公開用の案内修正はその後のコミットです。
- 元リポジトリの履歴とrc.5 Releaseは非公開のまま保持。公開側には匿名化済みmainとrc.5タグのみを送信します。バックアップ用refや元のコミットは送信しません。
- MSIとZIPは既存rc.5と同一バイト列を使用し、SHA-256を維持。再ビルド・署名変更・秘密鍵の追加は行っていません。
- ZIP内INSTALL.mdの「非公開・アクセス権が必要」という説明は公開前のものです。現行の導入説明とRelease Notesでは訂正済みです。
- ライセンスは現時点で未設定です。今回の移行でライセンスを新たに付与していません。
- ローカルoriginは公開用Sheaside、private-backupは元の非公開Sheaside-privateを参照します。過去のローカルコピーを使う場合は旧履歴を公開側にpushしないでください。

### 公開済みrc.5の対処（2026-10-26 承認済み）

rc.6の公開と、公開成功・匿名ダウンロード・ハッシュ一致の確認後にrc.5のMSI/ZIPを取り下げることが承認されました。rc.5のReleaseページには配布終了とrc.6への案内を追記し、Gitタグ・コミット履歴・開発記録を維持します。ただし、取得済みコピーや外部キャッシュの回収・完全削除は保証できません。同名ファイルの黙った差し替えは行いません。履歴内では該当パスを検出していないため、履歴書き換えや再移行を今回の対処として実施する必要はありません。

履歴の書き換え・force push・非公開バックアップの変更は行いません。監査結果の共有時は実際のユーザー名・パス・個人メールを再掲しないでください。
