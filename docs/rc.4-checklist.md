# 1.0.0-rc.4 手動確認

Excel 2013の自動COM・ホストUI検証と、人による実マウス・描画確認を区別する。このリストは手動未実施。Microsoft 365はすべて確認待ち。MSI再作成・公開・Microsoft 365インストールは今回対象外。

## 準備

Visual StudioでDebugビルド後F5起動。保存不要のテストブックを使用し、通常シート4枚、グラフシート1枚、HiddenとVeryHidden各1枚を用意する。表示設定は検証後に戻す。

- [ ] 独立Sheasideタブがなく、標準［表示］タブにSheasideグループがある。アイコン・日本語ツールチップが読める。
- [ ] 新規ブック／同じブックの［新しいウィンドウを開く］ではパネルが閉じている。
- [ ] ［シート一覧］で現在ウィンドウだけ開閉。パネルの×でもリボンの押下状態が解除される。
- [ ] ［非表示も表示］と［VeryHiddenも表示］は独立。両方ONで全状態を表示。Excel再起動後も値を復元する。
- [ ] 同一Excelインスタンスの別ブック・別ウィンドウへ設定が反映される。
- [ ] 表示OFFで除外された対象は選択から外れ、再度ONでも自動再選択されない。
- [ ] パネルはタイトル・ブック名・検索・追加/削除・一覧・件数。旧フィルターと設定画面がない。
- [ ] 検索文字がある間だけ解除ボタンを表示。解除してもリボンの表示設定は維持する。
- [ ] 表／棒グラフと目に斜線／鍵が区別でき、Visibleの状態アイコンは空欄。ホバーで種類・状態が分かる。
- [ ] 選択背景・アクティブ●・タブ色が混同されず、長い名前・狭い幅・水平スクロールでも読める。
- [ ] Ctrl、Shift、Ctrl+Shift、Ctrl+A、Esc、右クリックの選択仕様を維持する。
- [ ] 通常クリックとダブルクリックでアクティブ化／名前変更。Hiddenのクリックで勝手に再表示しない。
- [ ] 単一行を前後・先頭・末尾空白へドラッグ。変化のない位置へのドロップはExcelを変更しない。
- [ ] 非連続の複数行を選択し、修飾キーを離して選択済み行からドラッグ。元の相対順と選択IDを維持する。
- [ ] 複数選択中の未選択行からはその行だけを移動。Ctrl／Shift押下中はドラッグ開始しない。
- [ ] 検索結果・Hidden/VH除外中も移動。先頭は最初の表示行直前、末尾は最後の表示行直後。除外シートを直接移動しない。
- [ ] Hidden・VeryHidden・グラフ混在の複数移動後、表示状態・タブ色と実タブ順を維持する。
- [ ] ドラッグ中に別ウィンドウへ切替、設定変更、シート構成変更すると中止。別ブックを変更しない。
- [ ] 構成保護・読み取り専用・従来共有ブックで拒否。途中失敗は成功/失敗/未処理を報告し、実順序を表示する。
- [ ] 追加・削除確認・複製・非表示・再表示・VeryHidden・テーマ色/色なしの単一/一括操作が動く。
- [ ] パネル幅変更・Officeテーマ各種・高コントラスト・100/125/150/200% DPIで文字やアイコンが欠けない。
- [ ] Excel終了・再起動、複数インスタンス起動で例外がない。

## Microsoft 365で特に再確認する項目

上記全項目に加え、簡略化リボン／通常リボン、32/64bit Office、モニター間DPI変更、黒テーマ、非表示ChartのMoveと一時表示復元を確認する。開発環境Excel 2013での成功をMicrosoft 365の成功として扱わない。配布・インストール検証は別作業で実施する。
