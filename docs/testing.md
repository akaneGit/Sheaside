Microsoft 365 **64bit版**では、rc.6のインストール・起動・主要なシート管理機能・UI・アンインストール・再インストールをユーザー実機確認済みです。.NET Framework 4.8.1およびVSTO Runtimeを導入した環境です。

**新しい正式版1.0.0 MSIのMicrosoft 365実インストールは未実施です。** rc.6の結果を正式版MSIの実インストール結果とは扱いません。32bit Officeは利用禁止ではありませんが未検証・保証対象外です。その他未検証Office、旧版からの直接更新、修復は保証していません。

## インストーラー検証

実MSIでFindRelatedProducts・AppSearch・LaunchConditionsのみを実行し、製品インストール・削除やOSレジストリ変更は行いません。

- 2026-10-26の開発環境でrc.6を実際に検出。.NET/VSTOの検索結果は正常で、旧版アンインストールを求めて拒否することを確認。
- UI/Execute両シーケンスで旧版検出→LaunchConditions→InstallInitialize/RemoveExistingProductsの順序を確認。
- .NET Release 528039は拒否、528040・533320・533509は許可。両ビューの結果をセッション内で模擬し、実LaunchConditionsを実行。
- VSTOの欠落・0・1、rc.2/rc.5/rc.6検出の模擬、旧版なし・保守時の条件通過を確認。
- ProductCodeは正式版用に変更。UpgradeCode・Component GUID・HKCU登録先は維持。4ファイルを格納し、ローカルのマニフェストを参照。

構造・条件検証は実インストール後の全ケースを保証しません。同一ユーザーの関連MSIは検出できますが、ClickOnce・手動登録・別ユーザーを同様に検出できるとは限りません。既存版をアンインストールしてから正式版を導入してください。

.NETは公式WiXと同じ、raw DWORDの#接頭辞を考慮した6桁の.NET 4.x Release値比較です。将来桁数が変わる場合は再検証が必要です。実32bit OSでの検索は未検証です。
