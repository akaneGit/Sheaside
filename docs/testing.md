# 検証・既知の問題

## rc.6の確認範囲

2026-10-26のローカル検証結果：Debug/Releaseビルドは警告0・エラー0。管理430チェック、Excel 2013連携込み600チェック、VSTOホストUI21チェック成功。MSI構造27チェック、実MSI前提条件28チェック、配布整合性42チェック成功。2つのVSTOマニフェストはmageで署名検証成功、MSIは未署名です。

MSI前提条件テストでは生成MSIをWindows Installerのセッションとして開き、実レジストリに対してAppSearchとLaunchConditionsを実行しました。開発PCの両ビューで検出したReleaseは534296です。さらに、各ビューの検索結果プロパティへDWORD形式で528039（拒否）、528040・533320・533509（許可）を設定し、実際のLaunchConditionsアクションで結果を確認しました。欠落、VSTOの0/1、保守時の解除条件も検証しました。OSレジストリを書き換えた境界値テストや製品の実インストールは行っていません。実32bit OS上の検索は未検証です。

rc.5も同じ実レジストリでAppSearchを実行し、.NET・VSTOの旧条件が両方拒否することを再現しました。原因はraw DWORDの`#`接頭辞を考慮しない比較です。修正は[MicrosoftのRegLocator仕様](https://learn.microsoft.com/en-us/windows/win32/msi/reglocator-table)と[WiX 4.0.6の.NET 4.8判定](https://github.com/wixtoolset/wix/blob/v4.0.6/src/ext/NetFx/wixlib/NetFx48.wxs)に沿った、6桁の.NET 4.x Release値の比較です。将来Release値の桁数が変わる場合は比較方式の再検証が必要です。

rc.5 MSI/ZIPと旧rc.2成果物のSHA-256が変わっていないことを確認しました。rc.6候補は`artifacts/rc.6`に分離し、公開・タグ作成・pushは行っていません。公開DLL内パスの監査結果と対処待ちは[公開履歴の取り扱い](publication.md)を参照してください。

rc.5のMicrosoft 365導入で、Release=533509でも.NET不足と誤判定された事例があります。rc.6は検出条件を修正した未公開候補です。Microsoft 365での再インストール確認は未実施です。

## 準備

Visual StudioでDebugビルド→F5。標準［表示］タブ→Sheaside→シート一覧を開く。保存不要のテストブックに通常シート・グラフシート・Hidden・VeryHiddenを用意する。リボンの表示設定を両方ONにする。

- [ ] Hidden/VHをクリックしても情報ダイアログが出ず、Excelのアクティブシートと表示状態が変わらない。
- [ ] Hidden/VHをCtrl/Shiftで選択集合に含められる。ダブルクリック時も勝手に再表示しない。名前変更の既存動作は維持される。
- [ ] 右クリックの明示的な再表示が動く。成功通知はなく、保護等による失敗は通知される。
- [ ] パレットにテーマ色60個・標準色10個・色なし・その他の色・キャンセルがすべて表示され、不要な縦横スクロールバーがない。
- [ ] 標準色・テーマ色/濃淡・任意色・色なしを、単一/複数の通常シートとグラフシートへ適用できる。
- [ ] 黒・白・淡い色・赤などが左端の細い色バーとして表示される。色なしはバーが消える。選択背景と独立している。
- [ ] 種類アイコンは左、Hidden/VHと保護アイコンは名前の右。両状態が同時に表示され、線幅・中央位置が揃っている。
- [ ] 個別シートをExcel側で保護/解除すると盾が更新される。通常シートとグラフシートの両方で確認する。
- [ ] ブック構成保護だけでは盾が付かない。構成保護による管理操作の拒否は維持される。
- [ ] アイコンのツールチップは日本語で意味が分かる。省略された長い名前は全文を確認できる。
- [ ] 選択背景と別行のアクティブ●を区別できる。Ctrl/Shift/Ctrl+Shift、全選択、Esc、右クリック選択が維持される。
- [ ] 単一/複数・検索中のドラッグ、先頭/末尾空白への移動、挿入ラインが従来どおり動く。
- [ ] 追加・削除確認・複製・非表示・再表示、検索解除、リボン切替、複数ブック/ウィンドウの対象が正しい。
- [ ] 100/125/150%の実OS倍率でパレットと一覧を確認。狭いパネルでも名前と右アイコンが重ならない。
- [ ] Officeの明/暗テーマ・高コントラストで、選択背景・文字・状態アイコン・淡色バーが読める。

Microsoft 365では上記に加え、32/64bit Office、通常/簡略化リボン、モニター間DPI変更、テーマ切替・再起動を確認する。配布用MSIの作成とGitHub Releases公開は、この手動確認後の別作業。
