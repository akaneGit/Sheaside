# v0.6 シート一括管理

複数選択後、選択済み行の右クリック → ［選択したN件を一括操作］を使用します。ワークシート・独立したグラフシートの両方が対象です。単一シート用メニューと追加ボタンは複数選択中に無効になります。選択・マウス・ドラッグの既存実装は維持しています。

| 操作 | 確認・動作 |
| --- | --- |
| 一括削除 | 全対象の名前・件数を表示し、明示的な実行確認。表示シートを最低1枚残す |
| 一括非表示 | 全対象の確認後、Hiddenに統一。VeryHiddenからHiddenへの変更も明記。既にHiddenならスキップ |
| 一括再表示 | Hiddenを表示。VeryHiddenが含まれる場合は名前・状態付き一覧で確認。Visibleはスキップ |
| 一括タブ色変更 | 色選択ダイアログから固定RGBを設定。同じ色はスキップ |
| 一括で色なし | 色設定を解除。既に色なしならスキップ |
| 一括複製 | 元のタブ順で、各複製元の直後に1枚ずつ作成。元の表示状態を維持 |

確認画面はリサイズ・スクロール可能で、全対象名を省略せず表示します。既定のEnterとEscはキャンセルです。完了画面には成功・失敗・スキップ・未処理の件数と対象別の結果を表示します。複製では複製先名も表示します。

## 設計と安全性

- UIから渡す対象は内部IDのスナップショットです。サービス側でウィンドウ・ブック・元のタブ順・名前・表示状態を固定し、ダイアログ終了後と各処理直前にIDから再取得します。閉じたウィンドウ、所属変更、名前・表示状態変更、対象消失、読み取り専用・構成保護・従来の共有ブックを拒否します。
- 削除と非表示は未処理対象以外に表示シートが残ることを毎回確認します。グラフシートも表示枚数に含みます。削除のDisplayAlertsは既存サービスのfinallyで元へ戻します。
- 共通実行器は最初の拒否・例外で停止し、残りを未処理にします。実行前の検証失敗は全件未処理です。Excel操作はトランザクションではないため、成功済み変更を取り消しません。失敗対象にも部分変更があり得ることを結果に明記します。
- 既存のWorksheet／Chartアダプターを使用し、Excelのシートグループ化は行いません。UIスレッドで実行し、管理処理・タイマー更新の再入を抑止します。
- 非表示のコピー元に対するCopy(After)が期待する位置へ挿入しないケースをExcel 2013で確認したため、単一複製も含め、作成前後のID差分でコピー先を識別します。位置が違えば既存の安全なMove処理で元の直後へ移し、表示状態を復元します。Nextだけでコピー先を推定しません。
- VeryHiddenの直接コピーもExcel 2013が拒否するため、VeryHiddenの複製元は画面更新停止中だけ表示します。複製先を元の表示状態へ設定し、finallyで複製元と画面更新設定を復元します。外部イベント等で復元を拒否された場合も失敗として中断し、実状態を再取得します。
- 操作後はExcelの実状態を取得します。削除対象のIDだけを選択集合から除去し、全選択対象を削除した場合はアクティブシートへ戻します。色・表示状態・複製は元の選択集合を維持します。スクロール位置の維持は既存の差分更新を使用します。

## Microsoft 365での実機確認

Visual Studio 2026でDebug / Any CPUをビルドし、F5でMicrosoft 365のExcelを起動します。保存不要のブックに、表示ワークシートKeep・A・B、HiddenのC、VeryHiddenのD、表示・非表示の独立したグラフシートを用意します。VeryHiddenはVBAエディターのVisibleプロパティで設定できます。

1. Ctrl、Shift、Ctrl＋Shift、Ctrl＋A、Escを確認します。選択済み行の右クリックは選択集合を保ち、一括メニューに正しい件数が出ます。未選択行の右クリックは単一選択になります。
2. 一括メニュー表示中は単一操作が無効です。1件に戻すと名前変更・追加・削除・複製・色・表示状態が従来どおり動きます。複数選択中のドラッグは禁止、1件の通常ドラッグは並び替えになります。
3. A・B・グラフを選び［一括削除］。確認に全対象名・件数があり、Enter・Esc・キャンセルでは変化しないことを確認します。再実行して削除し、Keepが残り、結果が成功3件になることを確認します。
4. 全表示シートを選んだ削除・非表示が拒否されます。非表示シートが残るだけでは実行できません。表示グラフが対象外に残る場合は実行できます。
5. Visible・Hidden・VeryHiddenを混在選択して一括非表示。VeryHidden→Hiddenの説明と全対象名を確認します。既にHiddenの対象はスキップされ、他はHiddenになり、元の選択を保ちます。
6. HiddenとVisibleを一括再表示。Visibleはスキップされます。VeryHiddenを含めた場合は確認画面が出て、キャンセルでは変化せず、実行後は全対象が表示されます。
7. ワークシート・グラフを選び、一括タブ色変更で赤・黒・白を設定。Excelの色と一覧が一致し、同色はスキップされます。キャンセルでは変化せず、色なしで解除できます。
8. 非連続・Visible・Hidden・VeryHidden・グラフを混在選択して一括複製。全コピーが各元シートの直後にあり、内容・種類・表示状態を保つことを確認します。複製元の選択が維持され、結果に複製先名が出ます。
9. 同名シートを持つ2ブックで各一括操作を実施し、対象外ブックが変わらないことを確認します。同一ブックの2ウィンドウでも、独立した選択集合と一覧同期を確認します。特にグラフを含む削除を両ウィンドウから確認します。
10. ブック構成保護・読み取り専用で全一括操作が拒否され、選択・表示切り替えが使えることを確認します。確認画面中に外部VBA等で対象名・表示状態・存在・保護を変更できる場合は、実行直前に拒否されることも確認します。
11. テスト用マクロ等で処理途中に保護・削除拒否を発生させ、成功・失敗・未処理の名前と件数が実状態に一致し、残りが実行されないことを確認します。DisplayAlertsは処理前のTrue／Falseへ戻ることを確認します。
12. 多数行の途中までスクロールして色・表示状態を一括変更し、選択とスクロールを確認します。削除後は消えた行が選択から除かれ、全対象削除時はアクティブシートが選択されます。
13. リボン表示切り替え、Excel側のアクティブ同期、単一の追加・名前変更・複製・削除、グラフ表示、ドラッグ前後・先頭末尾を再確認します。ウィンドウを閉じて別ブックを開いても選択が混ざらないことを確認します。

## 既知の制約

- Microsoft 365でのv0.6実機確認は未実施です。自動連携環境はExcel 2013（15.0）で、マウス操作・ダイアログ表示と外部イベントのタイミングは上記手順で確認が必要です。
- Excel 2013の非表示自動化では、複数ウィンドウ操作後のグラフ削除が`0x800A03EC`で拒否されるケースがあります。変更前のv0.5.1コミットでも再現しました。この限定条件のテストは対象保持・警告設定復元を確認し、Microsoft 365では同じ例外を成功扱いしません。正常なグラフ削除は別の単一・一括操作テストで検証します。
- 一括処理は同期処理で、途中キャンセル・進捗バー・一括Undoはありません。多数の対象では各操作前の安全確認に時間がかかります。
- 失敗した操作自体が一部反映されることがあります。結果を確認し、実際の一覧から再選択してください。自動再試行・ロールバックはしません。
- 複製中はExcelがコピー先をアクティブにすることがあります。Sheasideの選択集合は複製元を維持し、Excelのアクティブ表示は実状態に従います。
- 名前や表示状態が確認後に変わった場合は、安全のため実行を中断して再確認を求めます。非常に古い未対応のシート種別は対象外です。
