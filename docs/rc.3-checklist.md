# Sheaside 1.0.0-rc.3 実機確認

Excel 2013でのユーザー操作確認用。Microsoft 365は全項目未確認。作業用ブックで確認し、Excelの版数・OS・倍率・テーマと結果を記録する。

## フィルター

- [ ] 検索文字だけを入力：フィルター強調・解除ボタンは表示されない。
- [ ] 状態/種類を指定：即時反映、アイコン強調、条件表示、外側の解除が表示される。
- [ ] 外側の解除を押す：状態/種類が「すべて」に戻り、検索文字は残り、解除ボタンが消える。ポップアップ内に解除は存在しない。
- [ ] フィルターボタン再クリック、Esc、ペイン内の別操作、Excelセル、別ウィンドウへの切替、ペインを閉じる操作でポップアップが閉じる。適用条件は残る。
- [ ] 画面幅/高さを縮めてもポップアップがペイン内に収まり、必要ならスクロールで全項目を操作できる。
- [ ] VeryHidden設定OFFでは候補・検索・選択から除外、ONで候補が現れる。設定OFFへ戻すと対象選択も除外。

## 描画・操作

- [ ] 追加/削除の高さ、アイコン/文字位置が揃い、ホバー・無効・キーボードフォーカスを識別できる。
- [ ] 検索・フィルター・設定アイコンが読める。125%/150%の実OS表示倍率と狭いペインで文字が欠けない。
- [ ] 通常/Ctrl/Shift/Ctrl+Shift、Ctrl+A、Esc、右クリックで選択が従来どおり。選択集合とアクティブ●は独立。
- [ ] グラフ/ワークシート、タブ色、Hidden/VeryHiddenラベルが識別できる。
- [ ] 単一選択のドラッグ前後移動、先頭/末尾移動。複数選択/絞り込み中は並び替えない。
- [ ] メニューの追加・削除・変更・複製・表示状態・色変更が従来どおり。削除確認と最後の表示シート制限を維持。
- [ ] Excel 2013の白/明るい灰色/濃い灰色、高コントラストで読める。

## 設定

- [ ] VeryHiddenの説明と、［表示］→［新しいウィンドウを開く］に関する説明が読める。
- [ ] 保存/キャンセルとスペースキーでのチェック操作が正常。125%/150%の実OS倍率でも全項目・保存ボタンが収まる。
- [ ] 初期表示OFFで新しいExcelウィンドウを作るとペイン非表示。現在のペインは変更しない。
- [ ] VeryHidden/初期表示の保存と再起動後の復元。既存のtheme/dockLeft属性が残っても起動正常。
- [ ] ペインの色と設定画面の配色が一致。設定画面を開き直すと最新のOfficeテーマを反映。
