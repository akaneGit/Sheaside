## 開始時調査

- 実際のUIはWinForms UserControl + CustomTaskPane。WPF/XAMLは存在しないためWinFormsを維持する。
- Excel操作はExcelWorksheetService / ExcelSheetアダプター、一括処理はExcelSheetBatchService / SheetBatchRunner、選択はウィンドウ別SheetSelectionState。
- 自動テストは独自STAハーネスとExcel 2013連携。Microsoft 365の実機確認は別途必要。
- 未コミット差分: Sheaside.slnxのProject Id、Sheaside.csprojのReorderableSheetListBox SubTypeとHostItem CanonicalName。調査済みだが今回の機能とは独立なので保持し、コミットから除外する。
- 新仕様を優先し、VeryHidden再表示・非表示の確認と正常完了ダイアログを廃止。VeryHiddenは既定で一覧から除外する。
