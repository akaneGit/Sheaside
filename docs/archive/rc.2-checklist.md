# Microsoft 365 実機確認 — 1.0.0-rc.2

全項目未実施。Excel 2013の自動COM連携テストをMicrosoft 365の結果として扱わないでください。作業用のコピーで確認し、Excelのバージョン・ビット数・Windows・Officeテーマ・表示倍率・実施日を記録します。

## 配布・ライフサイクル

- [ ] 配布ZIPを展開しSHA256照合。前提.NET Framework 4.8以上とVSTO Runtimeを確認。
- [ ] Office 32ビット環境にMSIを新規導入し、信頼確認後に起動できる。
- [ ] Office 64ビット環境でも同じMSIから起動できる。
- [ ] 前提ランタイム不足時は説明付きで導入拒否。組織の信頼ポリシーで拒否される場合は内容を記録。
- [ ] リボンの表示/非表示、×で閉じる、再表示、Excel終了・再起動が正常。新規ブックでも表示。
- [ ] 新しいウィンドウを複数作り、ブック切替・ウィンドウ終了時に別ブックや選択へ干渉しない。
- [ ] 同じMSIの修復、アンインストールでExcel登録・本体ファイルが削除され、再インストール可能。
- [ ] 次版MSIが用意された時点で手動更新・設定維持・旧版へのダウングレード拒否を検証。
- [ ] 旧ClickOnce版がある環境では先に削除し、MSI版を導入。二重表示しない。

## 操作・選択の回帰

- [ ] ワークシート3枚とグラフシート2枚を混在させ、Excelタブ順と一覧が一致。［グラフ］表示とクリック切替。
- [ ] 通常クリック単一選択、Ctrl切替、Shift範囲置換、Ctrl+Shift範囲追加が正常。アンカー連続操作も確認。
- [ ] 一覧にフォーカスを置いたCtrl+AとEsc。Excelのシートグループ化が起きない。
- [ ] 選択済み行の右クリックは複数選択保持、未選択行は単一選択。アクティブ●と選択集合を区別。
- [ ] ＋追加/削除が横並び。削除は単一/複数を対象とし、0件では無効。複数選択中の追加・名前変更は無効。
- [ ] メニューが追加/削除/区切り/名前変更/複製/区切り/非表示/再表示/VeryHidden/区切り/タブ色の順。
- [ ] 削除だけ対象名・件数・取り消せない旨を確認。キャンセルで無変更。正常操作後に成功通知・通常フッターなし。
- [ ] 名前変更の初期値・重複・31文字・不正文字。複製は元の直後、複数複製は元タブ順。
- [ ] ワークシート/グラフの前後・先頭末尾へのドラッグ。挿入ラインとタブ色が競合しない。
- [ ] 複数選択中・Ctrl/Shift中のドラッグは並び替えず、未選択行からのドラッグは1行のみ選択。不要な範囲選択なし。
- [ ] ドラッグ中に別ブック/ウィンドウへ切替するとキャンセル。失敗時はExcelの実順序に復元。

## 表示状態・検索・フィルター

- [ ] Visible/Hidden/VeryHiddenの表示が区別でき、非表示行クリックで勝手に再表示しない。
- [ ] VeryHidden表示OFF（初期値）では一覧・検索・フィルター候補・選択集合・操作対象から除外。
- [ ] 設定ONでVeryHiddenを表示し、単一/一括のVeryHidden変更・再表示が確認ダイアログなしで動作。
- [ ] 最後の表示シートを単一/一括削除・非表示・VeryHiddenにできない。グラフしか残らない場合も検証。
- [ ] 日本語・英字大小文字の部分一致検索がリアルタイムに効き、元のタブ順を維持。
- [ ] 検索右側のフィルターボタンから状態と種類を組み合わせ、アイコンの色と条件表示で適用が分かる。
- [ ] フィルター解除は状態/種類だけ解除し検索文字を保持。検索は文字を消せば解除。
- [ ] 絞り込みで消えた行を操作せず、解除後に古い選択が勝手に復活しない。絞り込み中は並び替え不可。
- [ ] ポップアップを開いたままペイン幅・高さを縮めてもペイン内に収まり、スクロールで項目を選べる。Escで閉じる。
- [ ] Excel側で名前・表示状態・色を変えると、Excelが前面で操作可能な時に約3秒以内/イベントで反映。

## テーマ・設定

- [ ] タブ色パレットのテーマ10色×6段階、標準色、色なし、その他の色が使える。
- [ ] ワークシート/グラフ混在の単一・一括色変更。色なしと黒が区別される。
- [ ] パレットのテーマ色を指定後、Excel側でブックのテーマを変更するとタブ色と一覧が追従。再度開いたパレットも新色。
- [ ] 標準色/任意RGBはブックテーマ変更で変化しない。テーマ色と同じ見た目のRGBへの変更でもテーマリンク解除。
- [ ] Officeカラフル・白・濃い灰色・黒でペインの文字が読める。Excel実行中のテーマ切替が反映。
- [ ] Officeテーマ検出不可・Windows高コントラストでも操作可能。検出不能時のWindows色フォールバックを確認。
- [ ] 設定はVeryHidden表示と初期表示だけ。保存・再起動で保持。旧theme/dockLeft値が残っても起動正常。
- [ ] ペインをExcel標準操作で左右/フロートへドラッグでき、設定変更で右側へ勝手に戻らない。
- [ ] 100/150/200%表示倍率と狭いペイン幅で、件数・行名・グラフ表示・操作ボタンが読める。

## 失敗・安全性

- [ ] 読み取り専用/構成保護/共有ブックの操作を拒否し、説明を表示。正常終了の通知はなし。
- [ ] 削除確認・色ダイアログ中に対象ブックの状態が変わった場合、再検証で拒否し別ブックを変更しない。
- [ ] 途中失敗は成功・失敗・スキップ・未処理を報告し残りを処理しない。Excel実状態から一覧復元。
- [ ] Excelが編集中・ダイアログ表示中でもクラッシュせず、終了後に一覧更新が再開。
- [ ] Hidden/VeryHidden複製・グラフ削除（特に複数ウィンドウの後）がMicrosoft 365で正常。
- [ ] 一時変更したDisplayAlerts・ScreenUpdating・表示状態が例外/キャンセル後も復元。

記録欄: 環境／項目／期待結果／実結果／再現手順／ログ・画面／判定。失敗があれば正式版へ移行せずRCを更新します。
