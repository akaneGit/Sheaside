# Microsoft 365 RC実機確認

未実施のチェックリストです。日付・実施者・Windows・表示倍率・Excelビルドと32/64bit・RCコミット・結果を記録してください。

テスト用ブックにKeep、A、B、日本語・長い名前、Hidden／VeryHiddenのワークシート、Visible／Hidden／VeryHiddenの独立グラフシートを用意します。別ブックにも同名シートを作り、同一ブックの［新しいウィンドウを開く］を使用します。

## 起動・選択

- [ ] DebugのF5、Release配布版の両方でリボンとパネルが起動する。
- [ ] ワークシート・グラフがタブ順に並ぶ。埋め込みグラフは行にならない。
- [ ] クリック・Enterで切り替わり、Hiddenは勝手に再表示されない。
- [ ] Ctrlの切り替え、Shiftの範囲置換、Ctrl＋Shiftの範囲追加と連続操作が正しい。Excelのグループ選択にならない。
- [ ] 一覧のCtrl＋A・Esc、検索欄のCtrl＋Aがそれぞれ適切に動く。
- [ ] 選択済み行の右クリックは選択を保持、未選択行は単一選択。名前変更・更新・並び替え後もIDで選択を維持する。
- [ ] 2ブック・同一ブックの2ウィンドウで選択集合とアクティブ表示が混ざらない。

## 管理メニュー

- [ ] 単一・複数で共通メニューを使用し、一括サブメニューはない。複数時の追加・名前変更は無効。
- [ ] 追加ボタン、ダブルクリック名前変更、不正名・重複名の拒否が従来どおり動く。
- [ ] 削除確認に件数・全対象名・取り消せない旨がある。Enter／Esc／キャンセルで削除されない。
- [ ] 単一・複数・グラフ混在で削除できる。成功ダイアログは出ない。削除したIDは選択集合から消える。
- [ ] 非表示・再表示・複製・色操作で不要な確認・成功ダイアログが出ない。
- [ ] Hidden／VeryHidden／グラフ混在の複製は各元の直後へ配置され、内容・状態を維持する。複数では元の選択を維持する。
- [ ] 最後の表示シートの削除・Hidden化・VeryHidden化は拒否。表示グラフが残ればワークシートを非表示にできる。
- [ ] 色・黒・白・色なしが一覧とExcelで一致する。既に目的の状態の対象はスキップ。
- [ ] 読み取り専用・構成保護・従来の共有ブックで管理操作を拒否し、理由を表示する。
- [ ] テスト用イベント／デバッガで途中に構成保護・対象削除を発生させ、成功・失敗・未処理を報告して残りを中断する。DisplayAlerts・ScreenUpdatingを復元する。
- [ ] 削除確認中に外部から名前・状態・存在を変更した場合、実行直前に拒否する。ブック切り替えで別ブックを誤操作しない。
- [ ] 2ウィンドウを行き来した後、両方からグラフを削除できる。Excel 2013の既知の拒否ケースをMicrosoft 365で別途判定する。

## VeryHidden・検索

- [ ] 初期状態でVeryHiddenが一覧になく、選択・操作できない。
- [ ] 設定ONでラベル付き表示。Visible／Hidden→VeryHidden、VeryHidden→Visibleを単一・複数で確認なしに実行できる。
- [ ] 設定OFFでVeryHiddenの選択も除外。再度ONでも自動再選択しない。
- [ ] 日本語・英字・大小文字を含む部分一致が入力に追従し、元の順序を保つ。
- [ ] 名前・状態・種類のAND条件、該当0件、解除が正しい。VeryHiddenフィルターで設定OFFを迂回できない。
- [ ] 除外された行を操作しない。全選択は表示行のみ。解除しても除外された選択を復活させない。
- [ ] Excel側の名前・状態・色・追加・削除を切り替えイベントまたは前面で約3秒後に反映する。

## ドラッグ・設定・終了

- [ ] 単一通常ドラッグで前後・先頭・末尾へ移動。挿入線とタブ色を区別でき、Esc・一覧外・ウィンドウ切り替えで中止。
- [ ] 複数選択・修飾キー・検索／フィルター・VeryHidden除外中は並び替えない。ドラッグによる意図しない範囲選択がない。
- [ ] 狭い／広いパネル、長い名前、125%／150%表示倍率で検索・一覧・件数・設定ボタンが使える。
- [ ] システム／ライト／ダーク・Windows高コントラストで選択・●・状態・タブ色が読める。
- [ ] 設定変更が同じExcelの各パネルに反映され、再起動後もVeryHidden・テーマ・左右・初期表示を維持する。
- [ ] 初期表示OFFでもリボンから開ける。×・リボン・別ウィンドウの表示が正しい。
- [ ] 保存確認のキャンセル、全ブック終了から再作成、ウィンドウ終了、Excel終了・再起動で例外・残留パネルがない。
- [ ] 別PCでsetup.exeから導入・更新・アンインストール・再導入を確認する。対象の32/64bitを記録する。

全項目の確認と不具合修正・回帰後、正式なv1.0へ進めます。
