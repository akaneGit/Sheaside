# v0.4.1 グラフシート対応

## 原因と修正

v0.4では一覧生成・対象検索が`Workbook.Worksheets`、アクティブ判定が`as Excel.Worksheet`、ドラッグの対象抽出が`OfType<Excel.Worksheet>()`に限定されていました。グラフシートのあるブックは開けましたが、グラフシート自身は一覧と管理の対象外でした。

[Workbook.Sheetsのコレクション](https://learn.microsoft.com/en-us/office/vba/api/excel.sheets)にはWorksheetとChartが含まれます。v0.4.1ではSheetsをインデックス順に読み、同じ順序を表示・ドラッグの境界に使用します。[Chart](https://learn.microsoft.com/en-us/office/vba/api/excel.chart(object))には独立したグラフシートと埋め込みグラフがありますが、後者はSheetsのメンバーではありません。

`ExcelSheet`は短命なCOMアダプターです。WorksheetとChartを明示的な型で保持し、各型のName・Visible・Tab・Activate・Copy・Delete・Moveを呼び分けます。ChartをWorksheetへキャストせず、共通操作にCellsなどのWorksheet専用APIを使いません。未知のCOM型は操作を拒否します。旧式のマクロ／ダイアログシートは今回の保証対象外です。

UIの既存DTO `WorksheetItem`に`SheetKind`を追加し、ID・種別・名前・表示状態・色をCOM参照なしで保持します。ChartのIDには`chart:`を付けます。IDはブック内の識別子であり、今後の複数選択は「ウィンドウ／ブックの操作コンテキスト＋IDの配列」で扱う設計を想定しています。一括操作時も、操作前の全対象検証・最後の表示シート判定が必要です。複数選択自体は今回追加しません。

## グラフシートの操作対応

| 操作 | 対応 |
| --- | --- |
| 一覧・クリック・Enter・アクティブ同期 | 対応。「［グラフ］」で区別 |
| 名前変更 | 対応。ワークシートとの重複も検証 |
| 複製 | Chart.Copyで元シートの直後に複製 |
| 削除 | Chart.Delete。確認と最後の表示シートの保護を維持 |
| 並び替え | Chart.Move。グラフ／ワークシートどちらも移動先に使用 |
| 非表示・Hidden再表示 | 対応。非表示行のクリックでは表示状態を変更しない |
| VeryHidden再表示 | 専用確認を経て対応 |
| タブ色・色なし | Chart.Tabで対応 |
| ［シートの追加］ | 選択したグラフシートの直後に**ワークシート**を追加 |
| 新規グラフシート作成・埋め込みグラフ編集 | 対象外。メニューを提供しない |

今回の管理メニューはWorksheet・Chartの両方に対応するため、Chartという理由だけで無効にする操作はありません。表示状態に合わないメニューは無効化し、構成保護・読み取り専用・従来の共有・閉じた対象などはサービスで再検証して拒否します。

- `Sheaside/Sheaside.csproj`：アダプターのCompile登録。
- `tests/ChartTests.cs`：グラフのUI・Excel連携テスト（新規）。

- `tests/SmokeTests.cs`、`tools/Test-Sheaside.ps1`：共通対象参照とテスト呼び出し・コンパイル登録。
- `README.md`、`docs/v0.4.1.md`：現行仕様・調査結果・実機確認手順。

## Microsoft 365の実機確認

自動検証：`tools/Test-Sheaside.ps1 -Excel`で既存回帰を含む341チェック成功。Debug / Releaseビルドは警告・エラー0です。

Visual Studio 2026で`Sheaside.slnx`を開き、Debug / Any CPUでF5起動します。保存不要なテスト用ブックを使ってください。

1. データ入りワークシートからグラフを作り、［グラフの移動］→［新しいシート］で独立したグラフシートにします。別のグラフはセル上に残します。
2. ワークシートとグラフシートを交互に並べ、Excelのタブ順と一覧が一致すること、独立したグラフだけに「［グラフ］」が付くことを確認します。
3. 一覧のクリック・Enterでグラフへ移動し、Excel側のタブ切り替えでも一覧の選択と「●」が同期することを確認します。
4. グラフ行のダブルクリックで名前変更し、ワークシートと同名は拒否されることを確認します。複製して元の直後に入り、タイトル・系列・書式が残ることを確認します。
5. グラフ行から［シートの追加］で直後にワークシートができること、グラフの削除確認でキャンセル／実行が正しく働くことを確認します。
6. グラフを先頭・末尾・ワークシート間へ、ワークシートをグラフの前後へドラッグします。挿入ライン・移動後の全タブ順・選択・スクロールを確認します。
7. グラフを非表示にし、クリックでは再表示されないこと、［再表示］で戻ることを確認します。VBEでグラフシートのVisibleをVeryHiddenにして、専用確認から再表示します。
8. Hidden／VeryHiddenの移動元・移動先でも並び替え、順序と元の表示状態が保たれることを確認します。
9. グラフのタブ色を赤・黒・色なしにし、一覧とExcelが一致することを確認します。Excel側の変更も前面表示中の約3秒以内、またはウィンドウ切り替えで反映されます。
10. 表示シートをグラフ1枚だけにして、非表示と削除が拒否されることを確認します。構成保護・読み取り専用でも管理操作が拒否されることを確認します。
11. 同名グラフのある2ブックと同一ブックの2ウィンドウで、クリックと変更が対象ブックにだけ作用することを確認します。ドラッグ中の切り替えは中止されます。
12. v0.4以前の追加・削除・名前変更・複製・並び替え・表示状態・色・リボン表示切り替えも再確認します。

自動連携テストの実行環境はExcel 2013 / 15.0です。Microsoft 365でのUI実機確認は未実施です。非表示の移動元・移動先は画面更新を止めて一時表示し、finallyで復元します。他アドインやVBAのイベントには一時状態が観測される可能性があります。既存のWindowsテーマ表示・条件付き3秒同期の制約は継続します。
