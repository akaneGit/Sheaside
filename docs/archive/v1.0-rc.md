## 設定と選択

設定は`%LOCALAPPDATA%/Sheaside/settings.xml`へ原子的に保存します。保存成功後にメモリ設定を変更し、同一Excelのパネルへ通知します。書き込み失敗は通知して以前の設定を保ち、破損時は安全な既定値に戻してトレースへ記録します。

検索・フィルターはウィンドウ内の一時状態です。除外行の選択を取り除き、再表示で選択を復活させません。全対象が除外された場合は表示範囲内のアクティブ行へ戻り、それもなければ選択0件です。検索・フィルターが有効なら全件一致でもドラッグを禁止します。VeryHidden除外で実タブ順との位置対応が異なる場合も禁止します。

## 安定化

管理処理はUIスレッドで行い、既存ガードでイベント再入・タイマー更新を抑止します。起動の二重登録を防ぎ、COM起動失敗でイベント・タイマーを解除します。Officeが先にイベント接続を切断しても、終了時は残りの解除とID登録の破棄を続けます。タスクペインの最終破棄はVSTOに任せます。

絞り込み中のドラッグは管理側とListBox側の双方で拒否します。非表示コピー・移動の一時変更はfinallyで復元します。外部イベントで復元自体を拒否された場合も失敗として実状態を再取得します。

VSTOホストの起動終了とRibbon／CustomTaskPaneの実表示は自動ハーネスで実行できないため、ソース確認と[実機チェックリスト](v1.0-checklist.md)の対象です。

## 既知の制約・未対応

- Microsoft 365の実機確認と別PCへのインストールは未実施です。正式版ではなくRCです。
- Excel 2013では複数ウィンドウ操作後のグラフ削除などを拒否する場合があります。変更前にも再現する条件では対象保持・警告復元を検証し、Microsoft 365の成功を代用しません。
- 一括処理は同期処理で、多数シートでは時間がかかります。途中キャンセル・進捗バー・一括Undo・自動ロールバックはありません。部分成功は通知します。
- テーマはパネルの基本色です。Officeテーマと自動連動せず、標準ダイアログや一部ネイティブ部品はWindows表示に従います。
- 左右と初期表示は保存しますが、寸法・フローティング位置・検索条件・選択集合は永続保存しません。
- 複数Excelプロセス間の設定即時同期はありません。設定保存は最後の保存が優先されます。
- 新規グラフ作成、古いマクロ／ダイアログシート、一括名前変更、複数シートドラッグは未対応です。
- 開発用証明書は配布先で信頼されていません。配布用署名・自動更新元・管理者向けMSIは未設定です。[配布手順](../deployment.md)を参照してください。
- 開始時のslnxのProject IdとcsprojのIDEメタデータは保持し、今回のコミットから除外しています。
